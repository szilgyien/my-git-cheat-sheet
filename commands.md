git status : Repository aktuális állapotának ellenőrzése
git clone : Letöltünk egy már létező Git projektet
git pull : Letöltjük a GitHubon lévő új változtatásokat
git push : Feltöltjük az új commitokat GitHubra
git diff : Megnézzük, mit módosítottunk
git log : Megnézzük a korábbi commitokat

git merge: ezzel nem vagyok tisztában
